
### **CST - Custom Server Titles, Chat, and Action Bar**

<!-- English Version -->
**CST** is a powerful and flexible plugin for Minecraft servers that allows admins and moderators to easily send personalized messages to players via titles, chat, and Action Bar. The plugin supports color codes, including HEX colors, making your messages more vibrant and attractive.

---

### **Key Features:**

- **Custom Titles:** Send players titles and subtitles with customizable fade-in, stay, and fade-out times.
- **Custom Chat Messages:** Send chat messages with support for color codes and HEX colors.
- **Action Bar Messages:** Send messages to the Action Bar (above the health bar) to grab players' attention.
- **HEX Color Support:** Use HEX codes to create colorful messages.
- **Flexible Commands:** The plugin supports sending messages to specific players or all online players.

---

### **Commands:**

1. **/ctitle [player] ; [title] ; [subtitle] ; [fadeIn] ; [stay] ; [fadeOut]**
   - Sends a personalized title and subtitle to the specified player or all players.
   - Example: `/ctitle * ; &aHello! ; &eWelcome to the server! ; 10 ; 70 ; 20`

2. **/cchat [player] [message]**
   - Sends a chat message to the specified player or all players.
   - Example: `/cchat * &cAttention! &fThe server will restart in 5 minutes.`

3. **/cactionbar [player] [message]**
   - Sends a message to the Action Bar of the specified player or all players.
   - Example: `/cactionbar * &aYou received a new item!`

4. **/chelp**
   - Shows a list of all available commands and their descriptions.

---

### **Permissions:**

- **cst.use** — Permission to use all plugin commands.

---

### **Configuration:**

The plugin supports multiple languages. You can select the language in the `config.yml` file:

```yaml
language: en
```
en,ru,de,es,ja,zh,fr
Available languages: en,ru,de,es,ja,zh,fr , and others if you add your localization files.

---

### **Installation:**

1. Download the plugin from SpigotMC.
2. Place the `CST.jar` file in your server's `plugins` folder.
3. Restart the server.
4. Configure the plugin via the config file and enjoy!

<!-- Russian Version -->

**CST** — это мощный и гибкий плагин для Minecraft серверов, который позволяет администраторам и модераторам легко отправлять персонализированные сообщения игрокам через заголовки, чат и Action Bar. Плагин поддерживает цветовые коды, включая HEX-цвета, что делает ваши сообщения более яркими и привлекательными.

---

### **Основные функции:**

- **Персонализированные заголовки (Titles):** Отправляйте игрокам заголовки и подзаголовки с настраиваемыми временем появления, задержки и исчезновения.
- **Кастомные сообщения в чат:** Отправляйте сообщения в чат с поддержкой цветовых кодов и HEX-цветов.
- **Action Bar сообщения:** Отправляйте сообщения в Action Bar (полоску над панелью здоровья), чтобы привлечь внимание игроков.
- **Поддержка HEX-цветов:** Используйте HEX-коды для создания цветных сообщений.
- **Гибкие команды:** Плагин поддерживает отправку сообщений как конкретным игрокам, так и всем онлайн-игрокам.

---

### **Команды:**

1. **/ctitle [игрок] ; [заголовок] ; [подзаголовок] ; [время появления] ; [время задержки] ; [время исчезновения]**
   - Отправляет персонализированный заголовок и подзаголовок указанному игроку или всем игрокам.
   - Пример: `/ctitle * ; &aПривет! ; &eДобро пожаловать на сервер! ; 10 ; 70 ; 20`

2. **/cchat [игрок] [сообщение]**
   - Отправляет сообщение в чат указанному игроку или всем игрокам.
   - Пример: `/cchat * &cВнимание! &fСервер будет перезагружен через 5 минут.`

3. /cactionbar [игрок] [сообщение]
   - Отправляет сообщение в Action Bar указанному игроку или всем игрокам.
   - Пример: `/cactionbar * &aВы получили новый предмет!`

4. **/chelp**
   - Показывает список всех доступных команд и их описание.

---

### **Разрешения:**

- **cst.use** — Разрешение на использование всех команд плагина.

---

### **Конфигурация:**

Плагин поддерживает мультиязычность. Вы можете выбрать язык сообщений в конфигурационном файле `config.yml`:

```yaml
language: ru
```

Доступные языки: en,ru,de,es,ja,zh,fr и другие, если вы добавите свои файлы локализации.

---

### **Установка:**

1. Скачайте плагин с SpigotMC.
2. Поместите файл `CST.jar` в папку `plugins` вашего сервера.
3. Перезагрузите сервер.
4. Настройте плагин через конфигурационный файл и наслаждайтесь!
